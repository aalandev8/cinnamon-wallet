# ADR-0002: Build against ERC-4337 v0.8 (EntryPoint 0.8.0)

- **Status:** Accepted
- **Date:** 2026-09-06
- **Deciders:** repo owner

## Context

The account must implement `IAccount` for a specific EntryPoint version. v0.7 has
the most mature tooling; v0.8 is the current standard and adds EIP-712 typed
signing and EIP-7702 support.

## Decision

Target **ERC-4337 v0.8 / EntryPoint 0.8.0**.

## Consequences

- `UserOperation` is signed as EIP-712 typed data; the `userOpHash` passed to a
  validator is an EIP-712 hash computed by the EntryPoint.
- Solidity `^0.8.28` and `evm_version = cancun` (transient storage).
- EIP-7702 (EOA → smart-account code) is compatible for a later phase.
- The canonical EntryPoint address is fixed cross-chain.
- Tooling (bundlers, SDKs) is slightly less mature than for v0.7 — accepted.

## Alternatives considered

- **v0.7** — most tutorials and reference code, but not where production is heading.
- **Start v0.7, migrate to v0.8** — rejected: do the adaptation work twice.
